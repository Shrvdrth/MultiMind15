Multi-Agent AI Decision Analysis Platform

Submit a business or technical decision. Three specialized AI agents debate it. A Moderator synthesizes the outcome with a confidence score — all streamed live in real-time.

Security
Built-In Security
🔑
JWT + Refresh Token Rotation
60-min access tokens · 30-day refresh tokens · Single-use rotation · Server-side revocation on logout
🔒
BCrypt Password Hashing
Salted BCrypt hashing · Minimum 8-character enforcement · No plaintext storage
🛡️
Prompt Injection Detection
15 known jailbreak/injection patterns checked via regex before any AI call is made
👮
Role-Based Access Control
AdminOnly policy on all admin endpoints · ProtectedRoute on frontend · AdminRoute guard
🌐
CORS Whitelist
Explicit origin whitelist — no wildcard origins · AllowCredentials only on known domains
🗑️
Soft Deletes + Global Filters
IsDeleted flag on all entities · EF Core query filters apply automatically · No data lost
