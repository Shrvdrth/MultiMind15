How it Works

A structured multi-round debate with live streaming and intelligent synthesis.

1

Submit Your Decision

Enter any business or technical question — architecture choices, build-vs-buy, hiring decisions, strategy pivots.

Prompt injection protection Duplicate caching (5 min) Rate limited: 70 calls/hr
2

Round 1 — Independent Analysis

All three agents analyze your question simultaneously with isolated memory — no groupthink.

Strategist Risk Analyst Engineer
3

User Input (Optional)

After Round 1, you can steer the debate — provide clarification, pushback, or additional context before Round 2 begins.

Live SSE streaming Adjustable direction
4

Round 2 — Cross-Agent Debate

Agents read each other's Round 1 responses and challenge, defend, or refine their positions.

Full conversation context Challenge & defend
5

Moderator Synthesis

The Moderator reads all rounds and produces a structured JSON recommendation: consensus points, disagreements, recommendation, and a 0–100 confidence score.

Confidence score Key themes Agreement analysis
6

Analytics & Export

View sentiment trends, agent agreement (Jaccard similarity), readability scores, and a multi-axis perspective radar. Export the full session as JSON.

Setup

Getting Started

Choose your environment and follow the steps below.

Recommended for most users. Runs backend, frontend, and Postgres in containers.

1. Create a .env file in the project root:

.env 
DB_PASSWORD=your-postgres-password
JWT_KEY=your-jwt-secret-at-least-32-chars
OPENAI_API_KEY=sk-or-v1-...
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=anthropic/claude-sonnet-4-5

2. Build and run:

bash 
# From the MULTIMIND project root
docker compose up --build

# Frontend  → http://localhost:3000
# Backend   → http://localhost:5000
# Postgres  → localhost:5432

Requires Node 20+, .NET 10 SDK, and a local PostgreSQL 16 instance.

1. Set up the database:

bash 
psql -U postgres -c "CREATE DATABASE multimind;"
cd backend/MultiMind.API
dotnet ef database update

2. Create appsettings.Development.json:

json 
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=multimind;Username=postgres;Password=YOUR_PG_PASSWORD"
  },
  "Jwt": {
    "Key": "your-jwt-secret-at-least-32-chars",
    "Issuer": "MultiMind",
    "Audience": "MultiMindUsers",
    "ExpiryMinutes": "60"
  },
  "OpenAI": {
    "ApiKey": "sk-or-v1-...",
    "Model": "anthropic/claude-sonnet-4-5",
    "BaseUrl": "https://openrouter.ai/api/v1"
  }
}

3. Run backend + frontend:

bash 
# Terminal 1 — Backend
cd backend/MultiMind.API
dotnet run --launch-profile http
# → http://localhost:5125  |  Scalar docs: /scalar

# Terminal 2 — Frontend
cd frontend
npm install
npm run dev
# → http://localhost:5174

Uses the manifests in k8s/. Tested with Minikube.

bash 
# 1. Build images
docker build -t multimind-backend:latest ./backend/MultiMind.API
docker build -t multimind-frontend:latest ./frontend

# 2. Load into Minikube
minikube image load multimind-backend:latest
minikube image load multimind-frontend:latest

# 3. Apply manifests (fill base64 secrets first)
kubectl apply -f k8s/secrets.yaml
kubectl apply -f k8s/postgres-deployment.yaml
kubectl apply -f k8s/backend-deployment.yaml
kubectl apply -f k8s/frontend-deployment.yaml

# 4. Open the app
minikube service frontend

Running Tests:

bash 
cd backend/MultiMind.API.Tests
dotnet test -c Release
# 22 unit tests: injection detection + DebateEngine logic

Features

Key Features

Everything you need for production-grade AI-assisted decision making.

🧠

Multi-Agent Debate

Three agents with isolated memory debate in parallel (Round 1) then cross-challenge each other with full context (Round 2).

⚡

Live SSE Streaming

Responses stream token-by-token to the browser via Server-Sent Events. No polling required during active debates.

⚖️

Moderator Synthesis

Final decision with a 0–100 confidence score, key consensus points, disagreements, and actionable recommendation.

💾

Response Caching

Duplicate prompts within 5 minutes return the existing session instantly — no wasted AI API calls or cost.

🛡️

Prompt Injection Protection

10 known jailbreak patterns blocked at the controller level before any AI call is made.

🚦

Rate Limiting

Max 70 AI calls per user per hour. Frontend debounce + submittingRef guard prevent double-submission.

📊

Analytics Dashboard

Sentiment trend, agent agreement (Jaccard similarity), multi-axis perspective radar, and readability scores.

📋

AI Call Logging

Every OpenAI request is logged to the AiCallLogs table with model, tokens, latency, and user ID.

🔄

Startup Cleanup

Orphaned running sessions from crashed containers are automatically marked failed on server restart.

🌟

Favourites & Export

Star any session and export the full debate transcript (all rounds + synthesis) as a structured JSON file.

👑

Admin Panel

Platform stats, user management, full debates list, and audit logs accessible to users with the Admin role.

🔐

Secure Auth

JWT HS256 tokens (60 min), BCrypt password hashing, forgot/reset password flow with time-limited tokens.

Built with React + .NET 10 + PostgreSQL + OpenRouter
